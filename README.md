# RunCoach

RunCoach — беговой помощник с Telegram Mini App. Сервер и стартовый экран готовы; анкета, хранение тренировок и подключение Polar — следующие этапы.

## Требования

- JDK 17 или новее
- Maven 3.6.3 или новее

## Запустить локально

```bash
mvn spring-boot:run
```

Откройте <http://localhost:8080>. Проверить ответ сервера можно по адресу <http://localhost:8080/api/status>.

## Кнопка запуска Mini App в Telegram

Telegram открывает Mini App только по публичному HTTPS-адресу. `localhost` подходит для просмотра страницы на этом Mac, но не для запуска из Telegram.

1. Получите публичный HTTPS-адрес для локального сервера на порту `8080` (например, через туннельный сервис).
2. Установите переменные окружения в терминале, где запускаете проект:

```bash
export TELEGRAM_BOT_TOKEN="новый-токен-от-BotFather"
export RUNCOACH_MINI_APP_URL="https://ваш-публичный-адрес"
mvn spring-boot:run
```

3. Откройте чат с ботом и отправьте `/start`. Бот ответит сообщением с кнопкой «Открыть RunCoach».

Секретный токен хранится только в переменной окружения. Не вставляйте его в исходники или сообщения. При отсутствии токена сайт запускается локально, без подключения к Telegram.

В IntelliJ IDEA выберите JDK 17 для проекта и Maven importer. Spring Boot запускается на Java 17, поэтому отдельное обновление JDK для первого этапа не требуется.

## Ближайшие этапы

1. Сделать анкету бегуна и формирование недельного плана.
2. Подключить хранение профиля и тренировок в PostgreSQL.
3. Добавить Telegram-бота с кнопкой открытия Mini App.
4. Изучить интеграцию Polar Flow и аналитику выполненных тренировок.
